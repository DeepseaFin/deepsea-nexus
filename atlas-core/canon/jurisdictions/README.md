# Jurisdictions Canon

This folder stores canonical jurisdiction knowledge for Deepsea Nexus.

Purpose:
- Represent country and region context used by Intelligence Engines.
- Provide structured jurisdiction references for policy-aware processing.
- Support consistent multi-jurisdiction interpretation.

Guidelines:
- Keep entries explicit, typed, and easy to audit.
- Store reference data only; no evaluation logic.
- Maintain separation between canon data and engine execution.
