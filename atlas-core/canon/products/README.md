# Products Canon

This folder stores canonical product definitions for Deepsea Nexus.

Purpose:
- Define institutional product knowledge in a typed, reusable structure.
- Provide product references consumed by Intelligence Engines.
- Preserve versioned, auditable product metadata.

Guidelines:
- Keep files declarative and strongly typed.
- Avoid business logic and runtime decisioning in canon artifacts.
- Treat this folder as source-of-truth institutional knowledge.
