# Business Passport Presentation ViewModel Contract

## Scope

This contract defines the Business Passport ViewModel consumed by the Customer Workspace Business Passport panel.

The panel must consume data through the existing presentation pipeline:

- `CustomerWorkspaceComposition.resolveBusinessPassportViewModel(...)`
- `BusinessPassportPresenter`

No direct domain model access is required in `CustomerWorkspace`.

## ViewModel Shape

Source type: `BusinessPassportPresentationViewModel`

Required fields:

- `id: string`
- `title: string`
- `subtitle: string`
- `metadata: PresentationMetadata`
- `sections: readonly PresentationSection<BusinessPassportPresentationField>[]`
- `payload.projection.passportId`
- `payload.projection.status`
- `payload.projection.lifecycle`
- `payload.projection.confidenceScore`
- `payload.projection.knowledgeDensityBand`
- `payload.projection.institutionalPulseState`
- `payload.projection.maturityLevel`
- `payload.projection.updatedAt`

## UI Mapping

- Header:
  - Passport ID <- `payload.projection.passportId`
  - Canonical Status <- `payload.projection.status`
  - Lifecycle <- `payload.projection.lifecycle`
  - Last Updated <- `payload.projection.updatedAt`
- Progress:
  - Completion Percent <- `payload.projection.confidenceScore`
  - Completion Label <- `${confidenceScore}% confidence`
- Structured sections:
  - Render from `sections[]` items generated by presenter
- Insights:
  - Not presenter-backed in current contract; panel renders empty state when none are supplied

## Empty / Error / Loading Behavior

- Loading: `PanelLoadingState`
- Error: `PanelErrorState`
- Missing ViewModel: section-scoped `PanelEmptyState`

## Notes

This contract intentionally keeps Business Passport rendering presenter-driven and composition-resolved so future Supabase-backed projections can flow through without UI architecture changes.
