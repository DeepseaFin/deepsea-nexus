# Decision Record Template

## Usage Notes

Use this template to capture strategic, policy, architecture, or operational decisions with full rationale and consequences.

## Metadata

- Document ID:
- Title:
- Domain:
- Decision Date:
- Owner:

- Status: Draft | Active | Superseded | Retired

## Purpose

State why this decision needed to be made.

## Scope

Define systems, teams, or governance areas affected by this decision.

## Context

Summarize the problem, constraints, and decision criteria.

## Decision

State the final decision in one explicit paragraph.

## Alternatives Considered

List alternatives and why each was rejected.

## Consequences

Describe expected benefits, trade-offs, and risks.

## Follow-up Actions

List implementation actions with owners and target dates.
