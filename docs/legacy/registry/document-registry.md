# Deepsea Legacy Document Registry

## Purpose

Provide the authoritative index of governed documents in docs/legacy, including ownership, status, and version metadata.

## Scope

This registry covers governance standards, templates, and future controlled documents published under the Deepsea Legacy Repository.

## Responsibilities

- Registry Steward
  - Maintain accuracy and uniqueness of document records.
- Document Owners
  - Ensure document metadata matches registry entry.
- Domain Custodians
  - Confirm ownership and status correctness during review.

## Process

1. Assign Document ID according to DOCUMENT-ID-STANDARD.
2. Add registry entry before final approval.
3. Verify version, status, owner, and path at publication.
4. Update entry with each governed change.
5. Mark superseded documents without deleting history.

## Examples

Example record fields:
- Document ID
- Title
- Domain
- Type
- Version
- Status
- Owner
- Last Reviewed
- Path

## Future Evolution

Planned maturity upgrades:
- Structured machine-readable export for reporting
- Automated drift detection between document metadata and registry records
- Domain dashboards for stale-document alerts
